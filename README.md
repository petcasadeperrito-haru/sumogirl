# SUMO GIRL LAB — サイト構築メモ

microCMS（`contents` / `settings` / `rikishi`）と `data/sumo.json` から静的HTMLを生成し、
Cloudflare Pages に公開します。依存パッケージなし。Node.js 18 以上。

## ファイル構成

```
build.mjs          全体の組み立て
rikishi.mjs        力士カード・一覧表・ランキング・決まり手
stats.mjs          成績の集計とランキングの算出
japan.mjs          日本地図（輪郭データを内蔵）
package.json
assets/style.css
assets/site.js     絞り込み・並べ替え・地図・文字サイズ
data/sumo.json     108力士・87決まり手のデータ
```

全部ルート直下でも `assets/` `data/` に入れても動きます。

## Cloudflare Pages

| 項目 | 値 |
|---|---|
| ビルドコマンド | `npm run build` |
| 出力ディレクトリ | `dist` |
| 環境変数 | `VITE_MICROCMS_SERVICE_DOMAIN` / `VITE_MICROCMS_API_KEY` / `SITE_URL`（任意） |

記事の公開を反映させるには、microCMS の Webhook に Cloudflare のデプロイフックを登録します
（`contents` と `settings`、`rikishi` を作ったらそれにも）。

## デザインの決めごと

- **配色**：生成り `#FBF9F4`／墨 `#1A1712`／金 `#7D601E`／朱 `#A8351F`（データ）／藍 `#244A7B`（データ）
- ヘッダーとフッターを墨の帯にし、金の罫で締める。相撲の正装（黒・白・金）から
- **金は文字色と強調のみ**、面には使わない。面に使うと安っぽくなる
- 朱と藍は**データ専用**。装飾には使わない
- 番付は縦書き（`writing-mode: vertical-rl`）。相撲で唯一、書式そのものが相撲を指す
- 数字はすべて等幅（`tabular-nums`）

## アクセシビリティ

すべて WCAG 2.1 AA を満たすよう設計しています。

- **コントラスト比**（生成り地に対して）本文16.98／副文7.33／淡色5.32／金5.60／朱6.25／藍8.53。
  墨の帯の上では本文16.01／淡色9.10／金8.91。操作部品の枠線は4.28（要3.0）
- **キーボード操作**：表の見出し、地図の円、絞り込み、表示切替すべて Tab で到達でき Enter/Space で作動
- **フォーカス表示**：金の3pxアウトライン。消していません
- **スキップリンク**：Tab を一度押すと「本文へ移動」が出ます
- **図版**：すべての SVG に `role="img"` と `<title>` `<desc>`。数値は本文にも文章で記載
- **並べ替え**：`aria-sort` で現在の状態を読み上げます
- **地図**：円は `role="button"` ＋ `aria-pressed`、結果欄は `aria-live="polite"`
- **文字サイズ**：ヘッダーの小・中・大で 100%／110%／122%
- `prefers-reduced-motion` と `prefers-color-scheme: dark` に対応

記事に図解SVGを入れるときは、`role="img"` と `<title>` `<desc>` を必ず付けてください。

## 地図のライセンス

`japan.mjs` の輪郭は、Wikimedia Commons の「日本地図」（Lincun 氏、CC BY-SA 3.0）を
トレース・簡略化した二次的著作物です。**継承条件により、この地図も CC BY-SA 3.0 で提供します。**
表示は `/map/` ページの下部に入れてあります。

継承条件を避けたい場合は、国土数値情報（出典明記のみ）の行政区域データから作り直せます。
その際は `japan.mjs` の `COAST` と `PREF` を差し替えるだけで済みます。

## データの更新

`data/sumo.json` は場所ごとに差し替えます。形式は
`{ rikishi: [...], kimarite: [...], lastBasho: {...} }`。力士には `rankHistory`（`{basho, rank}` の配列）、
`record`、`kimariteStyle`、`mawashiColor`、`from`、`heya` などが必要です。
`from` は `東京都` のように正式名で入れてください（地図の対応表と一致させるため）。

### 九月場所の更新（2026年10月10日）で増えた項目

| 項目 | 中身 | 表示される場所 |
|---|---|---|
| `results2026` | 2026年の各場所の番付・勝敗・休・備考（優勝や三賞） | 力士ページの「2026年の成績」、カードの「9月」の一行、表の「9月場所」列 |
| `record.year2026` | `results2026` の合計（幕下以下の場所も含む） | カード・力士ページの「2026」 |
| `kinboshi` | 金星の数 | 力士ページの記録 |
| `next` | 次の場所で決まっている昇進（例：`{basho:'2026-11', label:'新十両'}`） | カードの小さな札、力士ページ |
| `hidden` | 幕下十六枚目より下。東西の並びから外して、幕下の最後に番付順で並べます | 力士一覧 |
| `lastBasho` | 直近の場所の各段優勝・三賞・金星・次の場所の新十両 | トップの「九月場所の結果」 |

幕下の番付は `幕下12` の形で入れます（以前の `下12` から変更）。

ランキングの「2026年 勝率」と「部屋別」は、**十両以上の土俵で取った一番だけ**を数えます。
幕下から上がってきた力士の白星が混ざると、比べられなくなるためです。

### 数字の出どころと確かめ方

- 通算・幕内・優勝・三賞・金星・体格・2026年1〜7月場所：日本相撲協会の力士プロフィール
- 九月場所の勝敗：相撲協会の星取と、sumodb の場所別成績を突き合わせ
- 協会のページは場所中の途中経過（「十日目時点」など）が残っていることがあるので、
  その場合は途中の分を引いてから九月場所の最終成績を足しています
- 決まり手の比率（`kimariteStyle`）は今回は更新していません（一番ごとの決まり手の資料が要るため）

`tools/` は更新に使った作業用のスクリプトです。サイトの表示には使わないので、GitHub に上げる必要はありません。

## SNS用のページ

検索には出しません（noindex ＋ sitemap 除外）。リンクもしていないので、ブックマークして使ってください。

| URL | 中身 |
|---|---|
| `/cards/` | Instagram用カードの一覧。力士108・決まり手87・ランキング5の計200枚 |
| `/drafts/` | Xの下書き。文面をコピーして、直してから投稿します |

### カードの使い方

カードを開くと1080×1350（4:5）の枠が出ます。**枠の中をスクリーンショット**してください。
Windowsなら `Windowsキー + Shift + S` で範囲を選べます。

画面が狭いと縮小表示されますが、`Ctrl + -` などでブラウザの表示倍率を下げると、
等倍に近い状態で撮れます。きれいに撮りたいときは幅1200px以上の窓で開いてください。

### 下書きの使い方

そのまま投稿せず、**最後の一行を自分の言葉に直して**から使ってください。
リンクは本文に入れず、投稿したあとの**返信**に貼ると表示が伸びやすくなります。

文字数が140を超えると赤く表示されます。Xは全角140字まで投稿できますが、
タイムラインで折りたたまれずに読めるのはそのくらいまでです。
